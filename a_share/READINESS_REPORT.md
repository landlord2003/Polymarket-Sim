- ✅ 库存风险受控（盯市 + 全局上限 + 止损）

- ✅ 审计/对账/熔断机制齐备

### 仍差一步（需在国外环境完成，非本机可做）
- 🔴 安装依赖：`pip install py-clob-client eth-account`（注：`py-clob-client` 已归档，官方建议迁移 `py-sdk`，接口形态一致）
- 🔴 设环境变量：**`POLY_PK`(钱包私钥，运行时派生 L2 凭证) + 可选 `POLY_FUNDER`(邮件/代理钱包资金地址)**；不再需要 `CLOB_API_KEY/SECRET/PASSPHRASE`
- 🔴 EOA/MetaMask 钱包需一次性 approve USDC + 条件代币 给 3 个交易所合约（邮件钱包自动）
- 🔴 翻转开关：`LIVE=1 DRY_RUN=False`，限额 **$50–100 USDC**，仅 MM 腿，盯 1–3 天对账零差异、无熔断误触发后逐步放量

### 一句话结论
**代码与模拟层已达到"可接真钱"的生产级骨架；剩下的只是国外环境的依赖安装 + 2 行环境变量翻转 + 小额验证。**
本机无法替你完成"真钱激活"（需你的钱包密钥与国外网络），但已把这条路铺到"翻转即跑"的程度。
纯套利要真正成交，还取决于市场何时出现错价完整划分——那是行情条件，不是代码缺陷。

## 六、MM 参数四维扫描（mm × adv × tick × size，2026-08-30）

> 脚本 `mm_sweep4d.py`，560 组合全跑完（n=800/组合），报告 `MM_PARAM_SWEEP_4D.md`。

- **560 组合中 508 个（90.7%）稳健正 EV（95% CI 下界 > 0）**。
- 全局最优 `mm=0.03, adv=0.05, tick=0.001, size=300` → EV=+$6.59、胜率 100%、CI[6.33,6.85]。
- 全局最差 `mm=0.008, adv=0.30, tick=0.01, size=300` → EV=−$3.24、胜率 42.7%（高 adverse + 大 tick + 大 size 转负）。
- 关键规律：`adverse_frac` 是主导风险旋钮（低则强正、高则转负）；`tick` 越大滑点越狠；`mm` 越宽越安全。
- 生产默认 `mm=0.02, adv=0.15` 落在稳健区（如 `adv=0.15,tick=0.001,size=300` → EV+$4.25、胜率 98.9%、CI[4.06,4.44]），**无需调参即可实战**。
