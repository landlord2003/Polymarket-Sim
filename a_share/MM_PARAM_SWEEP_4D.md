# MM 参数四维扫描报告（mm × adv × tick × size，2026-08-30）

> 方法：在真实 `RigorVirtualBook.market_make` / `model_fill` 摩擦模型上做蒙特卡洛轮次回放
> （每轮 = 先买建仓后卖对冲，measure 锁利 PnL，与生产一致）。每组合 n=800 轮，
> 输出 EV / 胜率 / 95% 置信区间。脚本 `mm_sweep4d.py`，原始数据 `mm_sweep4d_results.json`。

## 维度定义
- **mm** (`mm_min_spread`)：策略接单的最小价差门槛（只接 `s ≥ mm` 的市场）
- **adv** (`adverse_frac`)：对冲基准价不利漂移占价差比例（买腿改吃完整价差后取得正期望）
- **tick** (`rigor.tick`)：订单簿档步（走簿滑点模型的档距；真实 Polymarket 为 0.001/0.002/0.005/0.01）
- **size**：单笔份额（决定走簿档数；`size > 顶档深度` 才触发走簿滑点）

网格：`mm∈{0.004,0.008,0.01,0.012,0.015,0.02,0.03}` × `adv∈{0.05,0.10,0.15,0.20,0.30}`
× `tick∈{0.001,0.002,0.005,0.01}` × `size∈{50,100,200,300}`（size 封顶 300 = 生产真实 max_skew 上限）
= **560 组合，全跑完**。

## 总体结论
- 560 组合中 **508 个（90.7%）稳健正 EV（95% CI 下界 > 0）**。
- 全局最优：`mm=0.03, adv=0.05, tick=0.001, size=300` → **EV=+$6.59 / 轮，胜率 100%，CI[6.33, 6.85]**。
- 全局最差：`mm=0.008, adv=0.30, tick=0.01, size=300` → **EV=−$3.24 / 轮，胜率 42.7%，CI[−3.94, −2.54]**。

## 关键规律（参数敏感性）
1. **`adverse_frac` 是主导风险旋钮**：低（0.05~0.15）强正；高（0.30）配大 tick + 大 size 直接转负。
   - 机理：adverse 越高，对冲基准价越保守（推离 mid 越多），能锁的利润越薄；超过阈值后吃不到完整价差，EV 转负。
2. **`tick` 越大滑点越狠**：`tick=0.01` 市场走簿时每档步长 10×，大单滑点显著恶化（尤其 size=200/300）。
3. **`size` 放大 EV 也放大滑点风险**：`size=300` + 低 adv + 小 tick 极佳；`size=300` + 高 adv + 大 tick 最差。
4. **`mm` 越宽越安全**：稳健正 EV 占比随 mm 单调上升（86% @0.004 → 98% @0.03）。

## 部署建议
- **守住房间**：`mm_min_spread ≥ 0.02`、`adverse_frac ≤ 0.15`、`size ≤ 300`。
- **优先小 tick 市场**（tick=0.001/0.002）：滑点友好，大单 EV 更稳。
- **避免**：`adverse_frac=0.30` + `tick≥0.005` + `size=300` 的组合（已证明转负）。
- 放大扫描 n（如 `SWEEP_N=2000`）可进一步收紧 CI，但 800 轮已足以区分稳健/脆弱区。
